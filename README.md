## What Is DTFFL Analytics?

DTFFL Analytics gives fantasy football managers a structured way to study NFL player production and league value. Built around nflverse data, it combines several seasons of analysis with player rankings, position reports, draft-planning tools, and roster evaluation features.

The platform is adapted for the DTFFL setting, with custom league-value formulas and half-PPR support. Its interactive dashboards cover keeper considerations, fantasy WAR, roster-worthiness scores, player age curves, and signals associated with breakouts or regression. Together, these tools support both draft preparation and day-to-day roster decisions.

- Analyze NFL players across multiple seasons.

## Typical Workflow

A normal analysis session can follow these steps:

1. Launch the DTFFL Analytics web interface.
2. Browse the available multi-season player data and position reports.
3. Verify the DTFFL scoring rules and roster assumptions.
4. Compare composite rankings with custom league values.
5. Use the draft-oriented tools to locate high-priority targets.
6. Consult keeper and roster-worthiness measures when evaluating lineups or retention choices.
7. Add age, breakout, regression, boom, and bust indicators to the evaluation.

## League Configuration

Set the analysis context to match the DTFFL scoring and roster structure. For example:

```yaml
league:
  name: DTFFL
  scoring: half-PPR
  roster_settings:
    customize: true
```

League-value formulas and roster context can be adjusted through the configuration controls or deployment settings provided by the project. The exact names of those controls can differ between builds.

## Frequently Asked Questions

### Who should use DTFFL Analytics?

The platform is designed for DTFFL fantasy football managers who need NFL player analysis, draft support, keeper evaluation, and roster-focused insights.

### Is half-PPR available?

Yes. Half-PPR is one of the league contexts represented by the product.

### Can the platform help with keeper selections?

Yes. Keeper analysis and roster-worthiness measurements are central components of its workflow.

### How does the platform calculate league value?

DTFFL Analytics offers custom league-value calculations based on the applicable scoring and roster configuration.

### What can I check when a dashboard fails to load?

Make sure you are running a current web build, confirm your internet connection, and reload the page. Also verify that all required league settings have been selected.
